## 🔑 关键技术栈

### 前端技术
- **框架**: Vue 3.4+ (Composition API)
- **状态管理**: Pinia 2.1+
- **类型系统**: TypeScript 5.0+
- **构建工具**: Vite 5.0+
- **UI库**: Element Plus 2.5+
- **Markdown**: marked 11.0+

### 后端技术
- **Web框架**: FastAPI 0.100+
- **ORM**: SQLAlchemy 2.0+
- **数据验证**: Pydantic 2.0+
- **认证**: JWT (python-jose)
- **限流**: SlowAPI
- **异步**: asyncio, aiohttp

### AI/数据技术
- **LLM**: DeepSeek Chat (deepseek-chat)
- **图数据库**: Neo4j 5.0+
- **关系数据库**: SQLite 3.0+
- **缓存**: Redis 6.0+ (可选)
