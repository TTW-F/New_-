# 前端新增页面说明

## 概述

为了让系统更加完整，新增了以下页面和组件，使系统从"只有登录和对话"变成一个功能完善的医疗问答平台。

## 新增页面

### 1. 首页 (HomeView.vue)
**路由**: `/`

**功能**:
- 系统介绍和特点展示
- 快速开始按钮
- 显示最近的对话记录
- 系统使用统计

**特点**:
- 渐变色背景，视觉效果好
- 卡片式布局展示系统特点
- 可以快速跳转到对话页面

### 2. 历史记录页 (HistoryView.vue)
**路由**: `/history`

**功能**:
- 查看所有对话历史
- 搜索对话内容
- 继续之前的对话
- 删除对话记录
- 分页显示

**特点**:
- 显示每个会话的消息数量和平均响应时间
- 支持搜索功能
- 确认删除对话框

### 3. 知识库页 (KnowledgeView.vue)
**路由**: `/knowledge`

**功能**:
- 搜索医疗知识（疾病、症状、药品、检查）
- 按类型筛选
- 查看实体详情
- 直接向AI咨询相关内容

**特点**:
- 知识库统计展示
- 热门搜索标签
- 搜索结果卡片展示
- 模态框显示详情

### 4. 个人中心页 (ProfileView.vue)
**路由**: `/profile`

**功能**:
- 查看个人信息
- 修改密码
- 退出登录

**特点**:
- 用户头像（首字母）
- 账户信息展示
- 密码修改表单
- 危险操作区域

## 新增组件

### 1. 导航栏 (Navbar.vue)
**位置**: `frontend/src/components/common/Navbar.vue`

**功能**:
- 全局导航菜单
- 用户信息显示
- 下拉菜单（个人中心、退出登录）
- 当前页面高亮

**特点**:
- 固定在顶部
- 响应式设计
- 渐变色激活状态
- 点击外部关闭下拉菜单

### 2. 主布局 (MainLayout.vue)
**位置**: `frontend/src/layouts/MainLayout.vue`

**功能**:
- 统一的页面布局
- 包含导航栏和内容区域

## 路由更新

更新了 `frontend/src/router/index.ts`，新增路由：

```typescript
'/' -> HomeView (首页)
'/chat' -> ChatView (对话页)
'/history' -> HistoryView (历史记录)
'/knowledge' -> KnowledgeView (知识库)
'/profile' -> ProfileView (个人中心)
'/login' -> LoginView (登录页)
```

## API 更新

更新了 `frontend/src/api/history.ts`，新增接口：

- `getSessionList(page, pageSize)` - 获取会话列表（带分页）
- `deleteSession(sessionId)` - 删除会话

## 工具函数更新

更新了 `frontend/src/utils/format.ts`，新增函数：

- `formatDistanceToNow(date)` - 格式化相对时间（如"3分钟前"）

## 使用说明

### 启动开发服务器

```bash
cd frontend
npm run dev
```

### 构建生产版本

```bash
cd frontend
npm run build
```

### 页面访问流程

1. 用户登录后，默认进入首页 (`/`)
2. 从首页可以：
   - 点击"开始咨询"进入对话页
   - 点击"历史记录"查看对话历史
   - 查看最近的对话并继续
3. 通过顶部导航栏可以访问所有页面
4. 点击用户头像可以进入个人中心或退出登录

- 加载状态提示
- 空状态提示
- 确认对话框

- 友好的错误提示

1. 所有新页面都需要登录才能访问（`requiresAuth: true`）
2. 部分功能（如知识库搜索）目前使用模拟数据，需要后端API支持
3. 修改密码功能需要后端API实现
4. 确保后端API路由与前端调用一致
